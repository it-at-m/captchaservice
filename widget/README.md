# CaptchaService Widget Demo

Minimal Vue + [ALTCHA](https://altcha.org/) demo for local CaptchaService integration.

**Setup and usage:** [Widget Demo](https://it-at-m.github.io/captchaservice/getting-started/widget-demo.html) in the CaptchaService documentation (or [`../docs/en/getting-started/widget-demo.md`](../docs/en/getting-started/widget-demo.md) in this repository).

## Scripts

| Command | Description |
| ------- | ----------- |
| `npm run dev` | Start the Vite dev server |
| `npm run build` | Production build |
| `npm run lint` | Check formatting, ESLint, and TypeScript |
| `npm run fix` | Auto-fix formatting and lint issues |
